### P2. Тренды и графики в терминале

- Команда `history`: читает накопленные SQLite-снапшоты и показывает динамику
  расхода по дням/неделям — сначала простой **ASCII-график** (спарклайн/бар-чарт
  без зависимостей), затем, при желании, полноценный **TUI** (кандидат —
  `charmbracelet/bubbletea`, как в `gitl`).
- Сравнение периодов («этот месяц vs прошлый»), разбивка по провайдерам и моделям.
- Именно ради этого история пишется в SQLite с Фазы 1, а не только текущий срез.

### P3. Алерты по порогу расхода

- Порог в конфиге (напр. `alert.monthly_usd: 200`); при `report`/`history`
  проверяется суммарный расход за окно и выводится предупреждение при превышении.
- Опционально — код возврата ≠ 0 при превышении, чтобы вешать в свой скрипт/cron
  на стороне пользователя (сам инструмент демоном не становится).
- **[TODO уточнить]** формат нотификации: только stderr/exit-code, или ещё
  локальные desktop-нотификации (кросс-платформенно — отдельная морока).

### P4. `--format=json`

- Машиночитаемый вывод `report`/`history` со `schema_version` (версионируемый
  контракт, как JSON-вывод в `gitl`). Golden-тесты на схему.
- Позволяет пользователю строить свои дашборды поверх без парсинга таблицы.
